# Automated Feedback Management Workflow (n8n)

## Overview
An n8n-based automation that collects customer feedback, analyzes it using AI, and categorizes it into **Compliment**, **Complaint**, or **Feature Request**, with structured storage in Airtable.

## Features
- Feedback collection via n8n Form Trigger  
- AI-powered classification using Google Gemini  
- Conditional routing with Switch node  
- Automated record creation in Airtable  

## Tech Stack
- n8n  
- Google Gemini (PaLM API)  
- Airtable  
- LangChain AI Agent  

## Usage
1. Import the JSON file into n8n  
2. Configure Google Gemini and Airtable credentials  
3. Activate the workflow  

## Notes
- API keys are not included  
- Use dummy data for testing
